## Changes Made

### 1. Audio Ordering Fix (`Server/jarvis_server.py`, `TTS/tts_service.py`, `ProjectInterface/index.html`)
**Problem:** Audio chunks from different TTS generations could arrive out of order, causing garbled playback.

**Solution:**
- Added `turn_id` field to track which conversation turn each audio chunk belongs to
- **Server (`jarvis_server.py`):** Both `handle_llm` and `handle_llm_service` now increment and propagate `turn_id` through `llm_start`, `llm_token`, `llm_end`, and `llm_audio` messages
- **TTS Service (`tts_service.py`):** Added `current_turn_id` to `QwenTTSProcessor`, passed through reset/accumulate, and included in all `audio_chunk` and `audio_end` WebSocket messages
- **Browser (`index.html`):** On `llm_start`, pending audio buffers are cleared and `expectedNextSeq` resets. On `llm_audio`, buffers from previous turns are cleared before accepting new ones

### 2. Interface Layout Update (`ProjectInterface/index.html`)
**Problem:** Interface did not conform to the specified layout in `ProjectInterface/Outline.md`.

**Solution:**
- Restructured layout: upper thin control pane (start/stop button + reset button) above a single conversation pane
- Conversation messages now displayed as chat-style bubbles: user messages on the left (blue-tinted), LLM messages on the right (green-tinted)
- Removed dual-pane layout in favor of unified conversation scroll area
- Updated CSS: removed separate user/LLM panes, added `.message-row`, `.message-bubble`, `.controls-pane`, `.conversation-pane`
- Removed duplicate reset button from LLM pane header

### 3. LLM Response Display Fix (`ProjectInterface/index.html`)
**Problem:** Each partial LLM token created a new message instead of updating the existing one.

**Solution:**
- Rewrote `updateLLMStreaming()` to check if message `llm-msg-${llmMessageCount}` exists; only creates new message when it doesn't exist
- Updated `appendUserMessage()` and `appendLLMMessage()` to use the new bubble DOM structure
- Fixed `setLLMCursor()` to work with the new DOM structure and properly append cursor span to message text element
- Added `escapeHtml()` helper to prevent HTML injection in messages

### 4. Stop Button Queue Clearing (`ProjectInterface/index.html`)
**Problem:** Stop button did not stop queued processes or clear outdated audio queues.

**Solution:**
- Stop button now sends both `stop` (to VAD) and `interrupt` messages to server
- Added `clearPendingAudioBuffers()` function to reset `pendingAudioBuffers` and `expectedNextSeq`
- Added `previousTurnId` tracking to detect out-of-order audio from previous turns
- `stopPlayback()` now resets all audio state including `currentTurnId` and `previousTurnId`
- `resetConversation()` also resets turn ID tracking

### 5. Conversation History Tracking (Verified)

**Solution:**
